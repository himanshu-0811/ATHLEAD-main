# Athlead — Sports Event Scheduler App

A full-stack sports event scheduling platform built with Flutter and Firebase, 
enabling users to discover, book, and manage sports activities across Mumbai.

## Features
- User authentication & profile management
- Discover and book sports events near you
- Real-time database synchronization
- Separate dashboards for hosts and users
- Event creation, scheduling & participation management

## Tech Stack
- **Frontend/Mobile:** Flutter, Dart
- **Backend:** Firebase Firestore
- **Authentication:** Firebase Auth
- **Deployment:** Firebase Hosting
